Planetes is a small, keyboard-friendly launcher for installed Steam and Epic games. This release adds an installer
and automatic updates.

### Install

Download **Planetes-win-Setup.exe** under Assets and run it. It installs for your user only, with no administrator
prompt, adds a Start menu shortcut and starts Planetes. Prefer no installer? Extract **Planetes-win-Portable.zip**
anywhere and run `Planetes.exe`. The "Source code" archives are for developers.

**Coming from v0.1.0?** v0.1.0 can't update itself. Quit it from the tray, delete its folder and install this
release once. Your settings and Start with Windows choice are kept.

Planetes runs in the background with a tray icon. Press **Alt+Space** to open it. If another app (such as
PowerToys) already uses Alt+Space, Planetes says so; choose **Edit settings…** in the tray menu and set another
hotkey, for example `{ "hotkey": "ctrl+alt+space" }`.

### New

- **Automatic updates.** Planetes checks this repository's releases 30 seconds after starting and then daily. A new
  version downloads in the background and installs the next time the launcher hides, then Planetes restarts in the
  background. Only the changed parts are downloaded. Add `"check_for_updates": false` to the settings file to turn
  this off.
- **Installer and uninstaller.** Uninstall from Windows Settings → Apps; this also removes the Start with Windows
  entry.

### Scope and known limitations

- Windows x64 only; tested on Windows 11.
- Steam and Epic only. No accounts, ownership syncing or artwork downloads.
- Steam type filtering relies on its local metadata cache; unknown entries can include non-games.
- A successful handoff means Windows accepted the request, not that the game reached its first frame.
- The app and installer are unsigned. Windows SmartScreen may warn on first run; choose **More info → Run anyway**.

`SHA256SUMS.txt` verifies the installer and portable ZIP. The `.nupkg` files and `releases.win.json` are the update
feed that installed copies read. License notices and build information are inside the installed folder. Report
reproducible problems through this repository's Issues.
