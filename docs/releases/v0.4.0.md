Planetes is a small, keyboard-friendly launcher for installed Steam and Epic games. This release adds a preview
panel with each game's key art.

### Install

Already on v0.2.0 or later? Nothing to do: Planetes updates itself in the background and installs the update the
next time the launcher hides.

Otherwise, download **Planetes-win-Setup.exe** under Assets and run it. It installs for your user only, with no
administrator prompt, adds a Start menu shortcut and starts Planetes. Prefer no installer? Extract
**Planetes-win-Portable.zip** anywhere and run `Planetes.exe`. The "Source code" archives are for developers.

**Coming from v0.1.0?** v0.1.0 can't update itself. Quit it from the tray, delete its folder and install this
release once. Your settings and Start with Windows choice are kept.

Planetes runs in the background with a tray icon. Press **Alt+Space** to open it. If another app (such as
PowerToys) already uses Alt+Space, Planetes says so; choose **Edit settings…** in the tray menu and set another
hotkey, for example `{ "hotkey": "ctrl+alt+space" }`.

### New

- **Preview panel.** The window is wider, and the selected game's key art and logo fill a panel beside the results,
  with its store, when it was last played and its playtime.
- **Steam art** is what Steam already keeps on your PC for its own library; nothing is downloaded.
- **Epic art** isn't stored on your PC, so Planetes downloads each Epic game's art once from Epic's own site (about
  250 KB a game, no login) and keeps it in `%LOCALAPPDATA%\Planetes\art`. Add `"download_art": false` to the
  settings file to turn this off. A game without art shows its icon over a blurred copy.
- Last played and playtime moved from the result rows into the panel.

### Scope and known limitations

- Windows x64 only; tested on Windows 11.
- Steam and Epic only. No accounts or ownership syncing.
- Epic playtime isn't shown, and an Epic game shows no last played time until it is launched from Planetes.
- Steam type filtering relies on its local metadata cache; unknown entries can include non-games.
- A successful handoff means Windows accepted the request, not that the game reached its first frame.
- The app and installer are unsigned. Windows SmartScreen may warn on first run; choose **More info → Run anyway**.

`SHA256SUMS.txt` verifies the installer and portable ZIP. The `.nupkg` files and `releases.win.json` are the update
feed that installed copies read. License notices and build information are inside the installed folder. Report
reproducible problems through this repository's Issues.
