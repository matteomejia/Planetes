Planetes is a small, keyboard-friendly launcher for installed Steam and Epic games.

### Download and run

Download **Planetes-v0.1.0-windows-x64.zip** under Assets, extract it, and open `planetes.exe`.
Rust is not required. The automatically generated "Source code" archives are for developers.

### Included

- Local Steam and Epic discovery with multiple Steam libraries and non-game filtering.
- Instant search, abbreviation matching, keyboard navigation and click-to-launch.
- Launch through the official store clients, then close Planetes after handoff.
- A compact, neutral UI with one blue accent, local game icons and reduced-motion support.
- Rescan (Ctrl+R), visible launch errors and single-instance Windows behavior.
- Portable executable with app icon and Windows version metadata.

### Scope and known limitations

- Windows x64; tested on Windows 11. macOS has a compile check but no packaged release yet.
- Steam and Epic only. No accounts, ownership syncing, tray process, updater or artwork downloads.
- Steam type filtering relies on its local metadata cache; unknown entries can include non-games.
- A successful handoff means Windows accepted the request, not that the game reached its first frame.
- The first build is unsigned. Windows may identify its publisher as unknown.

The `.sha256` asset verifies the ZIP's download integrity. Included license notices and build information
are inside the portable folder. Report reproducible problems through this repository's Issues.
